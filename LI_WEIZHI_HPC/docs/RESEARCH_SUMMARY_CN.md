# 科研工作总结 — 李伟志

**莫斯科国立大学物理系数学方向硕士研究生**

## 研究方向
线性反问题数值求解、迭代算法、数值线性代数、MPI 并行计算、通信开销与并行效率分析。

## 本人承担的工作
1. 根据已有共轭梯度类算法的数学公式、伪代码及研究需求，调整算法形式，独立编写 Python 数值实现。
2. 进一步将串行算法改写为 MPI 并行版本，包括二维笛卡尔进程网格、矩阵分块、局部矩阵乘法、列/行进程通信和集体归约。
3. 在部分 MPI 迭代程序中采用 `MPI.Allreduce_init` 持久化集体通信，并使用 `Start()` / `Wait()` 复用通信请求，以减少重复通信设置的需要；该优化已在代码中实现，但现有资料并未提供单独的实测加速百分比。
4. 参考已有计算—通信代价分析框架，针对本人使用的算法调整公式，编写 Python 程序，独立生成效率曲线并总结研究结论。
5. 完成 MPI 交叉近似算法原型、正则化预条件 CGNR 数值实验，以及基于多项式表示的反问题近似求解。

## 2026 年 5 月的研究结果
在参数化并行效率模型（迭代次数 16）下，针对三个矩阵规模，比较算法 A 与算法 B。在模拟的 64×64 进程网格下：200×160 的两者效率为 90.84% / 88.94%；2000×1600 为 99.11% / 98.94%；20000×16000 为 99.91% / 99.89%。三张图是本人独立得到的数值模型计算结果，并非实测 MPI 墙钟时间。该组参数下，两种算法的预测效率接近，而规模增大时通信开销的相对影响减小。

## 当前研究 — PCGR 及预条件共轭梯度方法
目前正在推进反问题中的预条件共轭梯度研究。已完成的 λ-PCG / 正则化预条件 CGNR 单机 Notebook 采用交叉近似构造低秩因子，再用 QR/SVD 重压缩，建立预条件器。针对 Notebook 中特定的合成反问题，输出为预条件器秩 16，PCGNR 迭代 1 次、未预条件 CGNR 迭代 14 次。该比较仅涉及给定停止准则下的迭代次数，不等于完成了运行时间或 PCGR 并行加速测试。
